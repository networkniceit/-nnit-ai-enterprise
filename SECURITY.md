# Security Policy

## Overview

Security is a top priority for NNIT AI Enterprise. We take all security vulnerabilities seriously and appreciate the efforts of security researchers and users who report them responsibly.

## Supported Versions

We provide security updates for the following versions of NNIT AI Enterprise:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

As this is a web-based platform, we continuously deploy security updates to the latest version. All users automatically receive these updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

### How to Report

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email security details to the repository maintainers
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce the issue
   - Potential impact assessment
   - Any suggested fixes (if available)

### What to Expect

- **Initial Response**: We aim to acknowledge receipt within 48 hours
- **Updates**: You will receive updates on the status at least every 7 days
- **Resolution Timeline**: We strive to resolve critical vulnerabilities within 30 days
- **Credit**: Security researchers who responsibly disclose vulnerabilities will be credited (unless they prefer to remain anonymous)

### Our Commitment

- We will work with you to understand and resolve the issue
- We will keep you informed of our progress
- We will publicly acknowledge your responsible disclosure (if desired)
- We will not take legal action against researchers who follow responsible disclosure practices

## Security Best Practices

For users of the platform:

- Use strong, unique passwords
- Enable two-factor authentication when available
- Keep your contact information up to date
- Report suspicious activity immediately
- Do not share your account credentials
- Review security notifications from the platform

## Bug Bounty Program

Information about our bug bounty program will be published as the platform matures.

Thank you for helping keep NNIT AI Enterprise and our users safe!
